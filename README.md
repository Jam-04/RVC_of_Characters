# RVC_of_Characters
Models of characters' sounds. Most of them are Japanese.

存放许多RVC模型的地方，均使用Retrieval-based-Voice-Conversion-WebUI（https://github.com/RVC-Project/Retrieval-based-Voice-Conversion-WebUI ）项目进行训练。

下载后格式均为 “角色名_用于训练的RVC版本号.zip”。解压后把模型文件exp_name.pth和added_xxx.index放到weights文件夹下。刷新音色列表，检查特征检索库文件路径是否正确，然后就可以训练了。

模型文件更新均为个人训练顺序。
